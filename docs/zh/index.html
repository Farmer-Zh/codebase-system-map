三个层级，一条清楚的阅读路径。

先理解系统全貌，再按需进入模块和节点。读者只需要看到真正有助于理解产品或实现的细节。

01

系统总览

仓库实现什么能力、承担哪些主要职责，以及一条完整的核心路径。

02

模块视图

有业务或运行意义的边界、关系、判断和结果，并使用读者熟悉的语言。

03

节点证据

职责、输入、输出、准确源码位置，以及仓库确实包含 LLM 时的真实 Prompt。

使用的开源组件

结构尽量小，依赖必须说清楚。

Codebase Memory 提供详细的仓库智能信息；Node.js 校验并交付地图；Viz.js、Graphviz 和 Expat 在独立 HTML 内渲染图形。

MIT

Codebase Memory

参考代码智能工具，负责仓库索引、架构分析、搜索、路径追踪和有范围限制的源码读取。

MIT

Viz.js 3.29.0

每份生成文档内嵌的 JavaScript 封装和 WebAssembly 图形渲染器。

EPL-2.0

Graphviz

编译进 Viz.js WebAssembly 的 DOT 布局引擎，负责生成图形的 SVG 几何结构。

MIT

Expat

由 Viz.js 对象代码间接包含的 XML 解析器。
